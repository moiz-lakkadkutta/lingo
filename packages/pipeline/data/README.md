# data/
- freq-de.txt, freq-en.txt — top 20 000 lemmas, most frequent first, rank = line number. Derived from hermitdave/FrequencyWords (OpenSubtitles 2018, content CC BY-SA 4.0, https://github.com/hermitdave/FrequencyWords) lemmatized with simplemma 2.0.0 (MIT). Regenerate: `pnpm --filter @lingo/pipeline build:freq` (needs network and a Python venv with simplemma==2.0.0). Sidecar `freq-*.meta.json` records source sha256, versions and how many name forms were stripped. These derived lists remain CC BY-SA 4.0.
  - The source lists are lowercase, so for German every form is looked up capitalised as well: a form whose capitalised lookup is a different known lemma (haus → hausen / Haus, hat → haben / Hat) credits both, except that the lowercase lemma must be attested by the list's other forms (≥ 1 % of the form's count — bitten and danken pass, hausen/tagen/zimmern do not). See `creditLemmas` in scripts/build-freq.ts.
  - Names are stripped before ranking (a listed name never has a rank), so the de fallback in names.ts — capitalised, uninflected, unranked → name — can fire.
- names-de.txt, names-en.txt — seeded from the same CC BY-SA 4.0 FrequencyWords lists (so they stay CC BY-SA 4.0; attributed in docs/aws.md). First names, surnames and places (people, cities, countries, brands, holidays) never highlighted: matched verbatim by names.ts and stripped from freq-*.txt at build time. One per line, sorted, hand-maintained; grown by the spot check. Seed rule (2026-09-18): a lowercase form of the raw list whose simplemma lemma is its own capitalised form in BOTH the German and the English dictionary (`lemmatize(w,'de') === lemmatize(w,'en') === Cap(w)`, e.g. anna → Anna in both, whereas frau → Frau only in de and hotel → Hotel/hotel) is a proper noun in both languages; that seed was eyeballed and common nouns, months, weekdays, demonyms, languages and foods removed (Halle, Roman, August, Berliner, Pilates…), then names the English dictionary knows as words (Bob, Bill, Frank, Max, Grace, Green…) were added by hand from the top 8 000 — for de only where the word is English vocabulary (Green, Hunter, Bill stay in freq-en.txt).
- .cache/ — downloaded sources, gitignored.

Try it without AWS: `pnpm --filter @lingo/pipeline cli prepare --clip demo-de --source s3://unused --lang de --native en --fixture --no-publish` (and `--clip demo-en --lang en --native de`) writes `work/<slug>/{clip.json,<lang>.vtt,native-<native>.vtt}` from the committed Transcribe fixtures.
