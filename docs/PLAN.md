## Non-negotiables
- Target cue 44 px bright; native cue 32 px cooler (#9FC9D8), ~70 %. Marker #E3C77A only for the word to learn.
- Cues ≤ 42 chars × 2 lines, ≤ 20 cps, 1–7 s, ≥ 2 frames apart. Highlights ≤ 40 % of cues; never names/numbers.
- SM-2 literal: 1 d → 6 d, ease 2.5; Again −0.20, Hard −0.15, Good 0, Easy +0.15 (see apps/api/src/lib/sm2.ts + tests).
- Free tier: 20 saved words/day. Lingo Plus: Challenge mode, unlimited saves, 0.75×.
- Level ≈ frequency band (A1 < 1000, A2 < 2000, B1 < 4000, B2 < 8000), labelled approximate.
